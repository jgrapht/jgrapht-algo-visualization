Glossary — colour refinement, the WL hash, and its blind spot
Colour refinement (1-WL)
Start by colouring every vertex with its degree. Each round, recolour a vertex by hashing its colour together with the sorted multiset of its neighbours' colours. Two vertices keep the same colour only while they look identical out to a growing radius. This is exactly org.jgrapht.alg.color.ColorRefinementAlgorithm.
Colour class
A set of vertices sharing the current colour. The partition only ever gets finer; when a round adds no new classes it is stable and refinement stops.
Round signature
A hash of the sorted histogram {colour: count} of one round. It ignores vertex identity and ordering, so isomorphic graphs produce the same signature every round.
Graph hash (fingerprint)
WeisfeilerLehmanGraphHash.getHash() folds the signatures of the initial degree round and every refinement round into one short digest — the value shown in the fingerprint stat and the verdict bar.
Necessary, not sufficient
Different fingerprints prove two graphs are non-isomorphic. Equal fingerprints do not prove isomorphism: 1-WL cannot separate some non-isomorphic graphs. Great as a fast pre-filter or content key, not a decision procedure.
The blind spot
A single 6-cycle and two disjoint triangles are both 2-regular, so colour refinement never splits them — identical fingerprints for non-isomorphic graphs. The 1-WL blind spot example shows exactly this collision.
What you're watching — fingerprinting two graphs at once

Both panes run the same 1-WL colour refinement that backs org.jgrapht.alg.hash.WeisfeilerLehmanGraphHash. Colours are canonical and shared across the panes: if a class in pane A is drawn the same colour as a class in pane B, the two graphs have an identical colour at that point. When the colour multisets agree every round, the fingerprints agree.

  • Isomorphic pair — the same graph, relabelled and its vertices/edges added in a scrambled order. The fingerprints are equal at every round: the hash is invariant under relabelling and insertion order.
  • 1-WL blind spot — hexagon vs. two triangles. Both stay one colour class forever, so the fingerprints match even though the graphs are not isomorphic. This is the necessary-but-not-sufficient caveat, made visible.
  • Distinguished pair — two forests with the same degree sequence that refinement does tell apart: the colour multisets diverge in round 1 and the fingerprints differ.

The verdict bar under the panes compares the final graph hashes — the same string getHash() returns in Java.
